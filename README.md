# Ловец вкусняшек (Веб-игра)

Браузерная аркадная игра, разработанная на чистом HTML5, CSS3 и JavaScript (Canvas API) по макету из Figma.

## Правила игры
- Игрок управляет кружкой на столе.
- Сверху падают различные предметы: еда (`🍫`, `🍙`, `🍛`) приносит очки (`SCORE`), а несъедобные предметы (`💩`) отнимают здоровье (`HP`).
- Начальный запас здоровья: **100 HP**.
- Игра заканчивается, когда здоровье опускается до **0 HP**.

## Управление
- **На компьютере:** перемещение курсора мыши по игровому полю или клавиши `⬅️` / `➡️`.
- **На смартфоне:** касание и перетаскивание пальцем влево/вправо по экрану.

## Структура проекта
- `index.html` — разметка игрового поля, HUD-панели и модальных окон.
- `style.css` — адаптивные стили (Flexbox, медиа-запросы для экранов 320–430px).
- `script.js` — игровой цикл, физика столкновений, генерация объектов и обработка событий.
- `assets/` — директория для графических ресурсов проекта.
